Teach4Free - Project Documentation
==================================

Project idea
------------

Teach4Free is a free educational platform where anyone can offer online classes, mentoring, help sessions or knowledge-sharing activities without any financial exchange.

The platform is based on a simple principle:

People teach what they know for free.
People learn what they need for free.
The only reward is reputation, trust and community prestige.

There will be no payments, credits, subscriptions, commissions, paid promotions or internal currency.

Core concept
------------

A user can be:

- A student.
- A teacher.
- Both student and teacher.
- An administrator.

Teachers will be able to publish free teaching offers, configure their availability, define the number of available seats, select the languages in which they can teach, and manage student requests.

Students will be able to search for free classes, filter by topic, language, level and availability, apply for a place, join waiting lists and rate completed classes.

The platform must be multilingual from the beginning.

Main goals
----------

1. Create a clean and pleasant platform for free online learning.
2. Allow people to offer classes without earning money or credits.
3. Allow students to find teachers by topic, language and availability.
4. Build reputation through stars, reviews, badges and completed teaching hours.
5. Protect the free nature of the platform with clear rules and moderation.
6. Support several languages from the beginning.
7. Keep the project technically clean, scalable and easy to maintain.

Important rule
--------------

The platform must stay completely free.

Forbidden:

- Charging students.
- Asking for payments.
- Selling private courses.
- Using the platform mainly to capture paying clients.
- Publishing commercial promotions.
- Hiding paid services behind free classes.
- Requesting donations as a condition for teaching.

Allowed:

- Sharing free resources.
- Linking to free documentation.
- Linking to free GitHub repositories.
- Linking to free educational videos.
- Mentioning professional experience without commercial pressure.

Google login has been added using Laravel Socialite.

- GET /auth/google/callback

The feature is optional and safe:

- The application still works with normal email/password authentication if Google credentials are missing.

Seat control and waiting list
-----------------------------

Teaching offers now support:

- allow_waiting_list
- waiting_list_limit

Seat behavior:

- Accepted applications count against max_students.
- Scheduled group and private request applications start as pending when seats are available.
- When accepted seats are full, new applications go to waitlisted if waiting lists are enabled and not full.
- If waiting lists are disabled or full, the application is blocked.
- Open public offers create accepted applications automatically while seats are available.
- When an accepted application is cancelled, the first waitlisted user is promoted.

Promotion behavior:

- Private request and scheduled group waitlisted users are promoted to pending.
- Open public waitlisted users are promoted to accepted.

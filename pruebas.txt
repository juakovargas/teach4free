Teach4Free - Manual Testing Notes
=================================

How to run tests manually
-------------------------

Install dependencies:

- composer install
- npm install

Prepare the local environment:

- copy .env.example .env
- php artisan key:generate
- Create a MySQL/MariaDB database named teach4free.
- php artisan migrate --seed

Useful checks:

- php artisan test
- composer run lint:check
- npm run lint:check
- npm run types:check
- npm run build

Run the application locally:

- composer run dev

Then open:

- http://127.0.0.1:8000

Application flow and notification task
======================================

Manual test instructions
------------------------

Run backend tests manually with:

- php artisan test

Run frontend type checks manually with:

- npm run types:check

Run the frontend production build manually with:

- npm run build

Useful browser checks:

- Register a new account and confirm that email verification is requested.
- Log in as user@example.com / password.
- Open /offers/laravel-for-beginners and apply from a verified non-owner account.
- Open /teacher/applications as the teacher account to accept or reject requests.
- Open /my-applications as the student account to view or cancel applications.
- Open /notifications and confirm unread/read behavior.
- Log in as admin@example.com / password and open /admin/applications.

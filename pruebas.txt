Teach4Free - Manual Testing Notes
=================================

How to run tests manually
-------------------------

Install dependencies:

- composer install
- npm install

Prepare the local environment:

- copy .env.example .env
- php artisan key:generate
- Create a MySQL/MariaDB database named teach4free.
- php artisan migrate --seed

Useful checks:

- php artisan test
- composer run lint:check
- npm run lint:check
- npm run types:check
- npm run build

Run the application locally:

- composer run dev

Then open:

- http://127.0.0.1:8000
